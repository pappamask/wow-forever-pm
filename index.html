Know what is settled

This is a planning guide, not a launch-tested quest addon. Race/class combinations follow Blizzard’s published Forever matrix; exact launch quests, transportation, tuning and talent allocations can change.

Launch verification list

  • Hall of Thanes treaty minimum level: sources conflict. First run stays at 15; return if necessary.
  • Confirm all dungeon quest pickups, prerequisite gates and rewards in the launch client.
  • Confirm Night Elf and Skyborne transfer routes before departure; reserve time for the Ironforge transfer.
  • Recheck the selected class talents, racial abilities, riding requirements and new-zone quest density.
  • Dungeon levels in this guide are suggested run targets, not entry requirements.
