# WoW Forever Alliance Leveling Guide

Interactive Alliance leveling guide for every official World of Warcraft: Forever race and class combination.

## Features

- Human, Dwarf, Gnome, Night Elf, and High Order Skyborne starting routes
- Race-aware class selector covering Druid, Hunter, Mage, Paladin, Priest, Rogue, Shaman, Warlock, and Warrior where eligible
- Class-specific leveling, gear, dungeon-role, and PvP guidance
- A saved-progress Next actions dashboard with milestone recovery and the next required dungeon
- Full required dungeon itinerary with quest checklists and class-quest verification reminders
- Record-level Beta, Classic baseline, and Placeholder confidence labels with last-reviewed dates
- Wowhead Forever links on authored quest and NPC mentions, using an exact record when verified and a search fallback when an ID is uncertain
- Contextual mouse-hover and keyboard-focus descriptions derived from quest pickups and objectives
- Class skill lookup with an exact-level picker, acquisition labels for known quest/talent/drop exceptions, and direct links to each live Wowhead Forever class ability database
- Browser-saved progress, notes, JSON backup/restore, and a prompt generator for future researched updates

Open **index.html** directly or use the GitHub Pages site. Progress is stored in that browser and does not sync through GitHub.

Returning-dungeon quests and the built-in skill milestones use labeled baselines where Forever data is not verified. A last-reviewed date records when the guide was checked; it does not guarantee that live game data is unchanged.
