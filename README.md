# WoW Forever Alliance Leveling Guide

Interactive Alliance level 1–60 route for every Alliance race and valid class, with class guidance, a trainer lookup, dungeon quest checklists, progress tracking, and a reusable update prompt.

## Open the guide

Use the hosted site at https://pappamask.github.io/wow-forever-pm/ or download `index.html` and open it in a browser. No installation or build step is required.

Progress stays in the browser. Export/import JSON or use the portable WFG1 code to move progress between devices. Personal progress is not committed to this repository.

## Quest routing

The level 1–30 route contains 185 unique curated quest records across 40 objective-area clusters. Each route stage lists what to pick up, the quest giver, pickup hub, objective area, and turn-in. Quest state is tracked as unknown, available, accepted, completed, or blocked. Dwarf and Gnome routes intentionally share 26 Dun Morogh records.

The guide also includes 34 dungeon run sections and 141 dungeon quest/chain entries. Every dungeon section appears in the journey sidebar, beside its planned stage. Six explicit zone visits show when to leave and return, reuse saved quest statuses, and display notes from the earlier visit. Current Forever findings, beta routes, Classic baselines, and unresolved placeholders are labeled separately. Links open Wowhead Forever records or Forever search results.

## Data

`guide-data.json` mirrors the route, early quest clusters, dungeon checklists, class data, sources, and confidence metadata used by the site.
